Quiet Note

号外

戻る場所は、
外ではなく、
自分の中にある。

最近、

何をやればいいのか分からない。
身体も、気持ちも、少し重い。

そんな声を、
よく聞くようになりました。

でも、

本当に必要なのは、
新しい刺激ではなく、

"戻れる場所"

なのかもしれません。

整うと、
感覚は少しずつ戻ってきます。

強さは、
外から足すものではなく、

もともと持っているものが、
通り始めること。

The Return

気が向いた日に届く、
ほぼ毎日の短いメール。

コーヒーが冷める前に、読み終わる。
でも、少し残る。

静かな強さへ戻る。

The Return を受け取る
